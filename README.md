# Empathia Project

## Backend (NestJS)

### Setup

1. Navigate to the backend directory:
   ```
   cd backend
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the backend server in development mode:
   ```
   npm run start:dev
   ```

The backend server will start on http://localhost:3000 and includes a Socket.IO gateway for real-time communication.
